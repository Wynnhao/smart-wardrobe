02

MVP 的五件事

P0 FEATURES · 其余见 PRD 负面清单
F1

批量拍照入库≤3 次点击 / 件

相册多选、端上压缩直传对象存储。北极星指标是录入:产品价值在 30 件衣物之前不成立,录入环节必须零门槛。

F2

AI 抠图与打标rembg + 多模态模型

云端自动去背生成透明 PNG;视觉模型输出品类、颜色、季节、场景、厚度的结构化标签,用户可滑动纠错,纠错数据回流。

F3

人台穿搭合成z-index 规则表

工具界面用写实中性人台(照片级衣服可信贴合);分享物料走全卡通管线。衣层叠放由品类规则表决定,不搞自由拖拽。

F4

明日天气推荐规则过滤 × LLM 组搭配

温度、降水、风力规则先硬过滤候选,大模型再从中组搭配并生成「为什么明天适合穿它」的理由——可解释,是留存关键。

F5

穿着日历cost-per-wear

一键「就这么穿」记入日历,沉淀单件穿着成本统计;年度穿搭报告在 P2 把记录变成回忆资产。

  • 规则先行:温度档 × 衣物厚度硬过滤,永不翻车;大模型只负责在候选内组合与解释。

三条硬约束(评审裁决)

形象两分法:工具场景用写实人台,传播场景用全卡通管线;「照片衣服直接贴卡通身体」列入负面清单。

AI 三律:AI 能力一律走可插拔网关;AI 产出一律带「AI 生成」标识;话术避开「AI 试穿 / AI 换脸」等深度合成触发词。

不做真实感试穿:开源 VTON 权重全部 CC BY-NC-SA 禁商用,商用 API 是成本与合规的双重陷阱——明确放弃。
